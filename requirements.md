Tech Stack Requirements:

- Frontend: React.js for building the user interface with Vite.
- Backend: Not needed.
-Database: Not needed.
- State Management: React's built-in state management (useState, useEffect).



USER STORIES

- As a user, I want to be able play tic tac toe against another player or against the computer.
- As a user, I want to be able to choose my symbol (X or O) and who goes first.
- As a user, I want to be able to see the game board and the current state of the game.
- As a user, I want to be able to make my move by selecting a cell on the board.
- As a user I want to be able to select computer's of different difficulty levels to play against.
- As a user, I want to be able to see the result of the game (win, lose, draw) and the option to play again.
